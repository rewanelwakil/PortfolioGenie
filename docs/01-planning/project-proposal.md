PortfolioGenie is a platform that helps junior developers create professional portfolios. Users enter their project details, the platform analyzes their GitHub activity, and AI generates optimized project descriptions and an "About Me" section.
## Objectives
- Let users enter their project details through a multi-step form.
- Analyze the user's GitHub activity.
- Use AI to optimize project descriptions for SEO and readability.
- Suggest a professional "About Me" section.
- Provide a live preview of the generated portfolio.
-  Allow users to sign up, log in, and keep their data saved.
- Provide a RESTful API (Node.js and Express) to manage projects and user data.
- Connect to an AI service through the backend.

## Scope
**Included:** the portfolio builder, the AI-generated content, the live preview , user accounts, REST API, GitHub integration.

**Not included:** payment system , multi-language support(English only) , full design customization (limited set of templates only)

**To be decided by the team:** publishing the portfolio online
